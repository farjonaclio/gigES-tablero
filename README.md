# Avance del campo · gigES

Tablero público del levantamiento de la evaluación final del proyecto ES-T1341 «gigES». CliOdinámica.

Muestra solo cifras agregadas: avance por grupo frente a la meta, cortes semanales, avance por solución, modo de aplicación y derivaciones. Toda cifra entre 1 y 4 se muestra como «<5». No contiene datos de personas.

Mientras `window.__ENDPOINT__` esté vacío en `index.html`, la página muestra **datos ficticios**, marcados como tales.
